# 参考范例：教师评语质量标准

- 学生：李某某
- 班级：207
- 班号：16
- 题目：Q2 一次户外活动的改变
- 内容：
- 语文与结构：
- 总分:

## 审题扣题
- 等级：做得很好
- 评语：全文紧扣"户外活动的改变"这一题眼，从起初的不太期待，写到途中经历后心境的转变，情节发展始终扣住主题，没有偏离方向，审题准确。

## 情节紧凑
- 等级：做得很好
- 评语：文章按出发、途中、抵达、观察与体验的时间顺序展开，脉络清晰，各部分衔接自然，读者能清楚跟随事情的发展经过，情节安排紧凑不散。

## 重点突出
- 等级：待加强
- 评语：文中最重要的心情转折——从疲惫抗拒到因景色放松——只用一句话带过，未被放大为全文焦点，建议把这最关键的一刻具体展开来写。

## 详略得当
- 等级：待加强
- 评语：像爬山、休息、与同学互动这类重要场景，写得比较简略，篇幅上没有分配到应有的详写，导致文章有经历的骨架，却少了让人印象深刻的重要片段。

## 情景交融
- 等级：待加强
- 评语：文中真实写出了从疲惫抗拒到逐渐放松、感受自然之美的心情变化，情感真挚；但不少景物描写仍与心情平行呈现，若能让写景与抒情相互映衬，感染力会更强。

## 多感官
- 等级：待加强
- 评语：你写出了树木、阳光、泥土、昆虫等具体的视觉细节，观察用心；但描写多集中在视觉，若能加入声音、气味、触觉等感官，画面会更立体生动。

## 修辞运用
- 等级：待加强
- 评语：个别句子写得比较平实、缺少变化，如描述心情好转时仅一笔带过；若能运用比喻、拟人等修辞手法，或换用更具表现力的词语，文字会更有画面感。

## 结尾照应／升华
- 等级：待加强
- 评语：结尾已点出自己在活动中的收获，但没有进一步联系生活与未来，写出这次经历更深层的意义，导致主题的升华不够，稍显意犹未尽。

## 教师总评
这篇文章紧扣主题，按时间顺序完整记录了户外活动的经过，写出了从疲惫抗拒到放松欣赏自然的真实情感变化，细节观察也很用心。不足之处在于：最关键的心情转折写得过于简略，重要场景的详略与感官描写不够丰富，语言变化偏少，结尾也未能进一步升华主题。建议把最打动自己的那一刻放慢写细，让写景与抒情紧密结合。
