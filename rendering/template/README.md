Visual Master v1 is the human-approved 1024x1536 raster diagnostic card. `layout_v1.json` is preserved as the original layout definition, `layout_v1_1.json` records the capacity correction, and the current production definition is the explicitly versioned `layout_v1_2.json`. All versions pin the same Visual Master SHA-256; Layout v1.2 retains the same field coordinates, colours and artwork. The production renderer uses Pillow with the pinned variable font at explicit weights (600 for general text and 700 for ratings), reserves the fixed rating-arrow region, and fails explicitly when approved Excel text cannot fit.

Each criterion field has its own fixed box. The renderer wraps the exact Excel text, measures the complete line block, and derives its centered position directly from that box. The eight criterion boxes intentionally follow the fixed raster master’s geometry rather than a cumulative row cursor. Layout v1.1 added explicit, finite fallback typography tiers for real production payload capacity; Layout v1.2 keeps those criterion settings, glyph-centers the top dynamic values from their own boxes, and gives the teacher summary a fixed 20px/24px safety-margin tier with a finite fallback. It does not continuously auto-shrink or rewrite text.
